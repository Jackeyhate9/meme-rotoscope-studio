## 1. 项目初衷与商业构想

* **核心灵感**：利用大模型对全网海量热门短视频（流行女团舞、打歌舞台、热门 BGM）进行角色重绘与替换。
* **爆款公式（极致反差感）**：
  $$\text{爆款指数} = \text{原视频时尚/高冷/帅气度} \times \text{替换角色的乡土/喜感/打破第四面墙指数}$$
  * *典型案例*：将 K-Pop 女团（如 aespa / BLACKPINK）C位舞步替换为“辽北第一狠人·范德彪（身穿维多利亚西装跳卡点鹰爪挠）”、将机械锁舞替换为“赵本山太空步”、将双人爵士舞替换为“李云龙 & 楚云飞”。

## 2. 技术可行性与瓶颈拆解

针对端到端自动化生成，技术链条拆解为三层：

### 2.1 轮询监控层（零成本爬虫 + 轻量 VLM）
* **抓取工具**：推荐开源的 `MediaCrawler`（支持抖音、B站、小红书）与 `yt-dlp`（YouTube）。
* **三级漏斗判定**：
  1. *Level 1 (规则过滤)*：过滤 10s-60s 之外、点赞/播放比异常的视频；
  2. *Level 2 (标题 LLM 分析)*：识别是否为单人/C位舞蹈、舞台名场面；
  3. *Level 3 (关键帧 VLM 视觉打分)*：抽 3~4 帧评估画面清晰度与背景整洁度。

### 2.2 视频生成与分镜切分（核心难点攻克）
1. **降维至 15 秒短片**：不碰 3~4 分钟的长 MV，专门攻关 15 秒高潮卡点片段。
2. **PySceneDetect 镜头切分**：不机械切片，按真实镜头切换点切成 3~4 个独立分镜（每段 4~5 秒）。
3. **主角 vs 伴舞识别（SAM 2 多目标跟踪）**：
   * 采用 Meta 开源的 **SAM 2**，在第 1 帧打标主角，生成整段 Mask 序列，只对主角局部 Inpainting 重绘，保留伴舞和舞台背景，极大抑制画面闪烁和算力浪费。

### 2.3 商业化防废品护城河（Auto-QC 质检 Agent）
* 商业模型（如火山引擎 SEED 2.5、快手可灵 1.5、MiniMax 海螺 H3）已自带成熟的“参考生视频/换角色”API。
* 商业 Agent 的真正壁垒在于 **【自动化质检与重抽闭环】**：
  * 生成完每个分镜后，VLM 自动抽帧打分（五官特征一致性、肢体畸变率、闪烁抑制）；
  * 若评分 `< 7.5`，系统在交付给用户前自动在后台微调参数免费重抽，保证成片交付率高于 95%。

## 5. C 端前端审美与产品架构 (`prototype.html`)

参考 **即梦（Dreamina）** 与 **B站 UpDream** 风格，采用高密度暗黑玻璃态美学，包含以下核心页面与闭环：

1. **灵感广场 (Explore)**：
   * 实时全网出片跑马灯广播；
   * 非对称 Bento Hero 动态视窗；
   * 8:4 门户双栏布局（左侧 6 组多元卡片，右侧“本日二创风云榜 Top 5”）。
2. **二创工作台 (Studio)**：
   * 原片 URL 智能解析与分镜探测；
   * 反差角色库快速点选（支持自定义上传）；
   * Agent 创意方案 A/B 一键注入；
   * 实时 SAM 2 绿色目标跟踪视窗与 3 镜头时间线。
3. **交付与导出页 (Delivery)**：
   * 原片与 AI 重绘成片双视窗同步对比；
   * **单镜头独立重抽（Re-roll）**：单镜不满意花 10 算力单独重新抽卡；
   * 导出 1080P MP4（嵌入国家防伪隐形水印）或剪映草稿包。
4. **收银台结算 (Checkout)**：模拟微信/支付宝扫码，即时充值并刷新全局算力。
5. **合规二级页面**：
   * 算法备案标识（网信算备 11010820260422 号）；
   * 创作者二创版权与肖像权公约全文；
   * Developer API 开发者合作申请；
   * 权利人侵权与肖像权即时下架通道（承诺 2 小时响应）。

## 7. 服务器与底层架构规划

* **不需要租用昂贵的 GPU 服务器**：
  * 重度显卡算力直接调用大厂 API，按需付费，无用户时算力成本为 0；
  * 自身服务器仅充当“调度员”（链接解析、CPU 切片、音轨缝合、账单计费）。
* **服务器选型建议**：
  * **本地测试期**：直接使用当前 PC（D 盘），0 成本运行；
  * **上线生产期**：阿里云/腾讯云轻量应用服务器（2核4G，¥30~¥60/月） + Cloudflare R2（0 出站流量费对象存储）。
