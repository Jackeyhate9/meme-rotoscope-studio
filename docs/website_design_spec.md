# MemeMorph 梗影AI — 商业化网站架构与审美视觉设计规范

本规范参考了 **字节跳动·即梦（Dreamina）** 的工业级暗色生产力布局与 **B站·UpDream** 的创作者社区反差美学，旨在打造一个兼具 **“高转化商业落地”** 与 **“极低操作门槛”** 的短视频鬼畜二创 SaaS。

---

## 一、 视觉风格系统（Visual Design System）

| 维度 | 设计规范 | 心理暗示与商业目的 |
| :--- | :--- | :--- |
| **主基底色 (Background)** | 极深曜石黑 `#0B0D14`，二级面板 `#131620`，边框 `rgba(255,255,255,0.08)` | 降低创作者在长时间视频微调时的视觉疲劳，契合科技暗黑与赛博夜场质感。 |
| **点睛品牌色 (Accents)** | 电光紫 `#8B5CF6` $\rightarrow$ 霓虹青 `#06B6D4` $\rightarrow$ 高光粉 `#EC4899` 渐变 | 具有强烈的二次元与鬼畜反差张力，激发用户的恶搞与分享欲望。 |
| **质感与光效 (Material)** | 磨砂毛玻璃 (`backdrop-blur-16px`) + 1px 细微高光边框 + 弥散光晕 | 营造类似即梦、Midjourney 官网的昂贵、高精度 AI 工具品质感。 |
| **状态信号色 (Semantics)** | 质检成功：翠绿 `#34D399`；渲染中：琥珀黄 `#FBBF24`；告警：荧光红 `#F87171` | 明确向用户传达“AI 质检（Auto-QC）”正在工作，提升对成片稳定性的信任。 |

## 二、 五大核心页面布局与交互逻辑

### 1. 首页：灵感广场（Explore & Trends）
* **定位**：通过热门二创成片激发创作欲，实现**“零思考一键同款”**转化。
* **核心模块**：
  * **动态 Hero 巨幕**：醒目标语“热梗穿梭，角色颠覆”，突出“一键生成 15s 鬼畜成片”与“无废品质检”。
  * **分类标签滑动栏**：东北刘老根宇宙、K-Pop女团、经典影视剧（亮剑/三国）、抽象Meme。
  * **瀑布流视频卡片**：
    * 卡片上悬浮显示：“15.2s · 3分镜”、“热度指数”、“原片名 $\leftrightarrow$ 替换角色”；
    * 悬停直接播放小样，右下角醒目放置 **【做同款】** 按钮，点击直接带参跳转至工作台。

### 3. 交付页：作品质检与多格式导出（Delivery & Inspector）
* **双视窗对比**：左侧展示原版视频舞步，右侧展示 SEED 2.5 换角后的 1080P 成品，音画完全同步。
* **分镜头素材包（增值服务）**：
  * 列出 3 个被切分的单镜头独立视频；
  * **单镜头重抽功能**：如果镜头 2 略微有瑕疵，用户无需消耗 45 算力重跑整段，只需消耗 10 算力单独重新抽卡镜头 2，由后端自动重新拼接。
* **多档位导出**：
  * 下载 1080P 高清成片（带原音轨）；
  * 导出剪映/PR 工程包（带时间戳和字幕草稿）；
  * 一键分发分享至灵感广场。

### 4. 支付与算力商城（Pricing & Credits）
* **阶梯式梯度定价**：
  1. **新手试水包**：¥19.9 / 200 算力（约 4 条成片，适合猎奇散客）；
  2. **爆款创作者包（主推高光）**：¥59 / 750 算力（约 16 条成片 + 极速并发免排队）；
  3. **MCN 矩阵月卡**：¥199 / 3000 算力每月（专属 GPU 节点 + API 批量调用）。
* **信任背书承诺**：页面显著标注“*AI 质检未通过自动免费重跑，失败 100% 自动退还算力*”。

### 5. 账号注册与法律防火墙（Auth & Compliance Modal）
* **低摩擦入口**：支持微信扫码、手机验证码一键注册，新用户注册即赠送 20 点体验算力。
* **合规与免责声明强制前置**：
  * 勾选框必须包含：《用户二创自律公约》与《生成式人工智能深度合成肖像权声明》；
  * 明确提示“本站为自动化辅助创作工具，用户对其上传的人物素材独立承担知识产权与肖像权责任”；
  * 成片自动在左下角渲染国标合规隐形/显式 AI 标识。
